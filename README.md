# Перевернуть доску

Небольшая статическая презентация в формате вертикальных карточек. Сейчас опубликована только первая карточка.

## Локальный просмотр

Откройте `index.html` в браузере. Сборка и сервер не требуются.

## Изменение карточки

- Текст, ссылки и структура находятся в `index.html`.
- Оформление и адаптивные размеры находятся в `styles.css`.
- Не добавляйте текст внутрь растровых иллюстраций: он должен оставаться HTML.
- Каждую следующую карточку сначала согласуйте отдельно. Добавляйте ее как отдельный `<article class="card">` и подключайте навигацию только после появления второй карточки.

## Публикация

Workflow `.github/workflows/pages.yml` автоматически запускается при push в `main`. В настройках репозитория в разделе **Pages** выберите **GitHub Actions** как источник публикации.
